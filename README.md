# CineFlow — indirilebilir sürümler

CineFlow Android uygulamasının kurulabilir APK dosyaları burada yayınlanır.
Uygulamanın kaynak kodu ayrı (özel) bir depoda tutulur.

## İndirme
En son sürüm: [Releases](../../releases/latest)

## Kurulum
1. Releases sayfasından `CineFlow-<sürüm>.apk` dosyasını indir.
2. Telefon/tablet veya Android TV'de dosyayı aç, "Bilinmeyen kaynaklara izin ver" isteğini onayla.
3. İlk açılışta TV modunu seç, TMDB API anahtarını gir (ücretsiz).

## Güncelleme
1.0.6 sürümünden itibaren uygulama açılışta bu deponun Releases sayfasını kontrol eder;
yeni sürüm varsa indirip Android kurulum ekranını açar.
